# Pengujian Phase 01

Jalankan `make test`. Pengujian memakai Python standard library hanya sebagai
pengendali host untuk merakit fixture, meluncurkan QEMU, membaca HMP monitor,
dan memeriksa RAM; reader, dispatcher, status, dan emitter yang diuji tetap
sepenuhnya Assembly.

Kasus default memeriksa ROM 64 KiB, reset vector, eksekusi sampai HLT, status
SUCCESS, 17 opcode, remaining nol, panjang emitter lima, serta output
`B8 34 12 50 58`. Tes overflow di firmware menguji batas tepat, satu byte
berlebih, dan emit16 dengan satu byte tersisa tanpa penulisan parsial.

Fixture IR 1–7 masing-masing mengharapkan error invalid magic, version,
length, unexpected EOF, unknown opcode, missing END, dan trailing data.
QEMU harus mencapai HLT error loop dengan status ERROR serta kode yang tepat.
Tidak ada generated bytes yang dieksekusi.

QEMU dinonaktifkan setelah setiap tes; tidak ada disk image, OS, BIOS
services, atau dependency Python pihak ketiga.
