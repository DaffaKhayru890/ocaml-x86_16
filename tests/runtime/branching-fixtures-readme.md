# Fixture kontrol alur

## Tujuan

Fixture pada `branching-fixtures.asm` adalah payload IR statis yang dipilih
oleh `IR_TEST_CASE`. Tiap kasus berjalan pada firmware dan QEMU yang sama
dengan program runtime; fixture error harus berhenti di compiler sebelum far
jump.

## Kasus valid

- 40: JMP forward melewati instruksi unreachable.
- 41: JNZ backward membentuk loop penghitung pada local slot 0.
- 42: JZ memilih jalur if/else dan merge dengan stack depth sama.
- 43: JNZ memilih jalur kedua.
- 49: dua terminal HALT reachable melalui branch.
- 50: LOAD_LOCAL unreachable sesudah HALT tidak mengubah validasi jalur
  runtime.
- 51: 129 relocation memicu batas tabel relocation pada emission.
- 52: 65 deklarasi label memicu batas tabel label saat analisis.

## Kasus invalid

- 44: merge menerima stack depth berbeda.
- 45: branch mereferensikan ID label yang tidak ada.
- 46: satu ID label didefinisikan dua kali.
- 47: label target berada setelah instruksi executable terakhir.
- 48: local hanya diinisialisasi pada satu jalur sebelum merge/LOAD.

## Register, alamat, dan eksekusi pengujian

Firmware membaca payload melalui CS:SI. Instruction/label tables berada di
DS=`6000h`; generated code berada di ES=`2000h`; hasil runtime berada di
`3000:0000`. Fixture tidak memakai register I/O, BIOS, atau layanan OS.
Assembler menulis ID label sebagai word little-endian sesuai format IR.

Jalankan `make test`. Harness mengompilasi setiap fixture, memastikan ukuran
ROM/reset vector, menjalankannya di QEMU, lalu membandingkan status, error,
hasil, dan seluruh generated bytes. Debug detail tabel tersedia di
`docs/debugging.md`.
