# Validasi machine code

## Pengantar

Emitter menulis byte ke buffer; keberhasilan setiap pemanggilan emitter
belum membuktikan bahwa urutan byte membentuk program yang benar. Modul ini
membaca kembali hasil codegen sebelum compiler melakukan far jump, lalu
mencocokkan setiap instruksi dengan template encoding yang diizinkan.

## Tujuan dan hubungan

`machine_code_validation.asm` dipanggil dari
`codegen_validate_generated_code` setelah emission dan relocation. Modul
menggunakan metadata dari instruction table/control-flow, konstanta opcode,
`comparison_select_jump`, dan output buffer. Jika pemeriksaan gagal,
compiler menyimpan `ERR_RUNTIME_INVALID` dan tidak menjalankan output parsial.
Disassembly `ndisasm` dan test expected bytes tetap dilakukan pada host
sebagai pemeriksaan independen.

## Register dan alamat

| Register | Fungsi |
|---|---|
| AX | Operand, ukuran template, target, atau displacement yang diharapkan |
| BX | Pointer instruction record dan offset buffer ES |
| CX | Dipakai prosedur pencarian/control-flow yang dipanggil |
| DX | Akhir instruksi branch untuk menghitung rel16 |
| ES:BX | Bytes generated code pada segment `2000h` |
| DS:BX | Record dan state compiler pada segment `6000h` |
| DI | Panjang akhir buffer; tidak diubah oleh validator |

Generated code berada pada `2000:0000–0FFF`; prologue 14 byte mendahului
instruksi pertama. Instruction table dimulai di `6000:0100`, label target
disimpan sebagai instruction index, dan output length ada di
`6000:000A`. Temp offset validator berada di `6000:004A`.

## Prosedur dan pemeriksaan berurutan

- `machine_code_expect_byte` dan `machine_code_expect_word` membandingkan
  byte/word output di ES tanpa menulis ke sana.
- `machine_code_instruction_size` memetakan opcode IR ke ukuran encoding.
  Ukuran menjaga batas record agar offset code berikutnya harus kontigu.
- `machine_code_validate_instruction_bytes` memeriksa byte-by-byte
  ICONST, local load/store, arithmetic, negasi, comparison, JMP, JZ/JNZ,
  serta seluruh tujuh byte sequence HALT.
- `machine_code_check_rel16` dan
  `machine_code_check_rel16_conditional` mengambil target instruction index,
  memastikan target executable, lalu membandingkan displacement little-endian
  dengan `target - (instruction_end)`.
- `machine_code_validate_generated_program` memastikan seluruh relocation
  telah diterapkan; memeriksa offset setiap record; memvalidasi setiap
  instruksi dan target branch; memastikan code berakhir tepat pada output
  length.
- `codegen_validate_generated_code` sebelum pemanggilan modul ini memeriksa
  flag, kapasitas, panjang, stack compile-time, dan byte prologue yang
  menetapkan DS=`3000h`, SS:SP=`4000:FFFE`.

Conditional branch mempunyai ukuran 8 byte:
`POP AX; TEST AX,AX; Jcc pembalik +3; JMP rel16`. Validator memeriksa
conditional short skip dan target near secara terpisah. Semua instruksi
yang didukung dicocokkan dengan template, sehingga tidak ada byte asing di
antara instruction record.

## Build dan debugging

Jalankan `make test-codegen`; suite mencocokkan generated bytes dari QEMU dan
menjalankan `ndisasm -b 16`. Untuk debugging compiler, periksa
`WORK_VALIDATION_OFFSET` (`6004Ah`), index instruksi (`60031h`), record di
`60100h`, code length (`6000Ah`), dan output di `20000h`. `make test-gdb`
memeriksa entry runtime dan byte HLT pada program default.
